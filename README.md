# Mamudou Saho – Portfolio

Personal portfolio of **Mamudou Saho**, full-stack developer and instructor at JCC.

## Stack

- [React 19](https://react.dev/) + [Vite 7](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://motion.dev/) for animations (respects reduced-motion settings)
- [React Icons](https://react-icons.github.io/react-icons/)
- [Formspree](https://formspree.io/) for the contact form

## Getting started

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run preview`, `npm run lint`.

## Editing content

All text content (profile, roles, services, projects, tech stack, social links) lives in
[`src/data/portfolio.js`](src/data/portfolio.js). Add a project by appending to `projects`
and dropping its screenshot in `public/`. Add a `repo` URL to a project to show a "Source" link.
